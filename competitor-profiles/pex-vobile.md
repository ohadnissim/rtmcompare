## Competitive Implications for UAI

**Where Pex/Vobile is strong vs. UAI**: Incumbent brand in rights management, combined copyright+AI pipeline, existing enterprise relationships, Vobile's video/audio scale

**Where UAI is strong vs. Pex**:
- Published accuracy metrics (F1=0.998) vs. Pex's opacity
- Per-stem analysis capability
- Certificate generation / audit trail
- Self-service API + SDK + desktop app
- More documented generator coverage
- Transparent developer documentation

**Opportunities**: Target distributors frustrated by Pex's opacity. Lead with per-stem capability and certificates as proof of depth. Position as "the API you can actually evaluate."

**Threats**: If Pex publishes accuracy benchmarks and matches UAI's performance, their existing copyright-ID customer base could lock UAI out of major DSPs.
