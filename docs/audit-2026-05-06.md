**Net:** the suite has been hardened impressively across 5.2.0 → 5.2.4 — every named regression check passed and the genre/mood removal is clean. But three structural items have outrun the patch cycle:

2. **RTM Send 1.0.0 has shipped against 5 different RTMcompare versions** with no protocol versioning.
3. **Zero automated tests** across 4 releases. Playwright skeleton at deferral 4.

These are 5.3-sprint items, not 5.2.4 ship-blockers — but they should be on the calendar before any new feature work.

## P0 — ship-blockers for next promotion

### Suite-level

1. **Electron 33 EOL** (senior-security · tech-debt)
   `package.json` and `rtm-profile-app/package.json` both pin `electron@^33.4.11`. Electron 33 reached EOL April 2026; latest stable is 38.x/39.x. Chromium security fixes are not flowing into your bundled runtime. Bump in lockstep across both apps and re-pack.

2. **RTM Send symlink-following on WAV/sidecar/.ready** (senior-security · prior P0 #4)
   Zero `O_NOFOLLOW` / `O_EXCL` / `lstat` / `FILE_FLAG_OPEN_REPARSE_POINT` in `rtm-send-plugin/Source/`. Receiver-side `processReadyMarker` also does no `lstat` before `fs.renameSync`. A same-user attacker can pre-place a `.wav` symlink to e.g. `~/.ssh/authorized_keys` and have the suite move it for them. **Mitigated only because** `assertSafeAudioPath` realpath-resolves before `read-audio-file` — that's one chained mitigation away from a write primitive.

3. **RTM Send `.ready` cryptographic binding still missing** (senior-security · prior P1 #9)
   No HMAC/SHA-256 over the `(wav|json)` triple. A sketchy plugin in the same DAW session can race-rewrite the WAV between the `.ready` write and RTMcompare's open. Headline scenario: engineer A/Bs a master that scored A+ in RTMcompare, ships it; client says it sounds wrong. Tweet thread: *"RTMcompare lied to me."* One-line fix in `writeSidecar`.

4. **RTM Send loop region capture is sample-inaccurate (±1 buffer / ~10.7 ms)** (audio-engineering · spatial-audio · adversarial · prior P0 #1)
   Block-level PPQ comparison in `PluginProcessor.cpp:135-174`. The whole "phase-cancel against source" pitch in marketing copy is false for loop/last-N captures until this lands. ARA path is sample-accurate by construction — the live capture should mirror its discipline. **5th deferral.** Adversarial agent's verdict: bump RTM Send to 1.1.0 with this + #2 + #3 fixed before any other lens's findings ship.

### RTMcompare renderer

5. **a11y blockers — three WCAG fails** (a11y-audit)
   - `FileDropZone` is keyboard-inaccessible (no `role`, `tabIndex`, `onKeyDown`, no hidden Browse) — **SC 2.1.1**
   - `ProgressBar.tsx` has no `role="status"` / `aria-live` — analysis progress silent for SR users — **SC 4.1.3**
   - `.drop-zone::after` 2.8 s `rtm-dropzone-pulse` not guarded by `prefers-reduced-motion` — **SC 2.3.3**
   - ~30 sites use `text-sand-700`/`text-sand-600` as visible text at 1.3–1.7:1 — **SC 1.4.3**
   - `SpecDriftBadge` `role="dialog"` has no Escape handler / focus trap / return-focus

6. **DMR removed from renderer but still in 100% of v5.2.4 docs** (ui-ux-pro-max)
   `BatchView.tsx:21` confirms "DMR / Releases / Audit log workflow removed." But Manual Chapter 5, Features Surface 5/6, Pitch Slide 6 all describe DMR prominently. Either re-add the surface or trim the docs before users read them.

7. **ThemeContext + ShellContext provider values not memoized** (react-best-practices)
   `ThemeContext.tsx:35` and `ShellContext.tsx:74` repeat the **exact** ModesContext-pre-5.2.4 unmemoized-value bug. Inline object literal + fresh function each render → all consumers re-render every parent render. Same one-line fix as 5.2.4 (`useMemo` value, `useCallback` setters).

8. **`setCurrentTime` 60Hz re-render of full ABPlayer during playback** (react-best-practices)
   `ABPlayer.tsx:657` calls `setCurrentTime(...)` every rAF. The 5.2.0 TpMeter fix solved the meter, but the transport clock + waveform progress div still re-render the entire 1700-line component at 60 Hz. Same anti-pattern, different consumer.

## P1 — should fix soon

### Architecture & contracts (senior-architect · api-design · ddia)

- **PythonJobRunner abstraction missing.** 5 spawn sites in `electron/main.ts` (master-chain-render, encoded-preview-render, translation-render, references-add, declick) re-implement spawn/cleanup, none register with `activeJobs`. Windows cancellation leaks orphan Python on every long render except `analyze-files`. Extract → all four hardenings land for free.
- **`.ready` / `.rtmprofile` / `.rtmalbum.json` are all unversioned** in practice. `AlbumSession.version=1` is *written* but never *read*. RTM Send sidecar has `pluginVersion` but RTMcompare doesn't branch on it. First protocol break is silent breakage. Stamp `protocolVersion` + tolerant-additive rule, document in `docs/protocol.md`.
- **Untyped error envelope.** Three incompatible shapes coexist (throws, `{ok:false,error}`, `{error}`). Renderers see raw stderr tails. Define `BackendError {code, kind, message, stderrTail?, exitCode?, retryable}` and route everything through it.
- **No back-pressure.** Renderer can fire N parallel renders → main spawns N Pythons → each may spawn demucs+ffmpeg children. ARG_MAX (~256 KB macOS, 32 KB Windows) is the only ceiling on `analyze-batch`. 500 long Dropbox paths could blow it.
- **Multi-window race conditions on `~/.rtm/*.json`.** `writeHistorySync` is naked `fs.writeFileSync`; concurrent writers race; `references.json` does tmp+rename but `history.json` doesn't.

### Code & docs

- **TP-as-warning sweep incomplete** (code-reviewer). 5.2.4 cleaned the verdict path but `BatchView.tsx` (CSV/JSON exports + red rendering) and `dspProfiles.ts:349-358` (`severity: 'block'` "limiter will engage on ingest") still emit it. User direction was "no warnings at all, just numbers."
- **89 `as any` casts unchanged** (code-reviewer · tech-debt). Concentrated in `App.tsx` (25), `devShim.ts` (8), `MasterAssistantPanel.tsx` (6), `SongDetailPanel.tsx` (6). Discipline held — count flat — but the cluster still hides drift.
- **Hex literal count grew 1528 → 1663** in `src/`. Top offenders: `BatchView.tsx` (141), `EngineerTipsPanel` (13×#d0b066), `SongDetailPanel` (12×), `ABPlayer` (10×). Multiple-gold-per-view risk.
- **TonalIssues local hex palette unchanged** (P2 #21 prior). 22 hex literals in one file.
- **AAC encode preview / downmix don't use object trajectories** (spatial-audio). Parser extracts them; `atmos_comparator` ignores them and routes objectless objects to phantom centre at 0.707/0.707.
- **Binaural TP labelled `"approx-ILD (no HRTF)"` in code** but UI surfaces a hard number. Rename "ILD-approx headroom" or swap in libspatialaudio/SADIE HRTF.
- **ADM 5.1.4 vs 7.1.2 ambiguity** unresolved — `adm_parser.py:54-55` admits "we default to 7.1.2 for 10 channels and let metadata override," but the override path is **not implemented**. A 5.1.4 file is silently labelled 7.1.2.
- **ADM RF64 rejected** in `bwf_writer.py:175-176` — Atmos masters ≥ 4 GB will not ingest. Material gap for film/long-form.
- **Apple object cap is `>` 118 not `>=`** (`adm_parser.py:463-466`) — 118 itself passes. Apple's tooling treats 118 as inclusive cap; behaviour at exactly 118 is ambiguous.

### UX

- **Click-to-copy still has no toast feedback** in `CategoryCard` and `HumPanel` (P2 #24 NOT FIXED). Pattern exists in `EQExportButton`/`ApplyBounceButton`. Extract `useToast()` and wire.
- **Triage Mode discoverability weak.** Lives as `text-[10px]` opacity-low button. First-launch users won't find it.
- **Compare CTA microcopy ambiguity** — `Begin analysis` is the same string for fileA-only and A+B. Fix: `Compare A vs B` / `Analyze single file`.
- **Microcopy register inconsistency** — dev-tone error strings (`'Failed to load album session: ...'`) next to friendly strings (`"That drop didn't include a file. If it's an iCloud/Dropbox placeholder…"`). Pick one voice.
- **Features PDF voice inconsistent** — Manual + Pitch nailed the new fun-and-easy register; Features still chops. Worth a second pass.

### a11y P1

- **SpectrumOverlay BandSolo strips remain mouse-only** (P0 #6 partially closed; SVG now has `role="img"` + `aria-label` + SR `<table>`, but solo interaction isn't keyboard-reachable).
- **A/B selector lacks `aria-pressed`** in `ABPlayer.tsx:1238/1266`.

### Tests / CI

- **Zero automated tests across 4 releases.** Playwright skeleton at deferral 4 — closer to abandoned than postponed (rule of thumb: 3 deferrals = backlog, 5 = abandoned). 2-day Playwright skeleton spec + 1-day pytest + 0.5-day JUCE UnitTest = **3.5 dev-days** to lock the top 12 risks numerically.
- **Mac DMGs built locally**, not in CI. Codesign identity in user memory. No lint gate, no typecheck gate, no test gate in CI.

### Security follow-ups

- **`rtm-incoming-list`** returns absolute paths inside `~/.rtm/inbox/` to renderer; `meta.json` parsed in main and broadcast verbatim. Same-user attacker can plant arbitrary JSON. Schema-validate on read.
- **`processReadyMarker` does no `lstat`/regular-file check** before `fs.renameSync`.
- **`master-chain-render`/`encoded-preview-render`/`translation-render` write configs to `os.tmpdir()` without `mode: 0o600`.** Prior 5.2.2 debug-log fix didn't reach these.
- **`render-pdf` data: URL has no CSP** in the hidden BrowserWindow. Sandbox + contextIsolation mitigate; CSP `<meta>` belt-and-suspenders.

## P2 — debt / nice-to-have

- **Dead code lies.** `singleFileHelpers.ts:9-11` doc-comment claims TP-as-HOLD; code below contradicts. `StreamingPreview.tsx:312-313` permanently-dead `{false && row.tp_breach && (...)}`.
- **`generation_loss_detector.check_mdct_periodicity`** mislabels MDCT period (1024 vs 2048). Functionally still detects; rename comment to "1024-sample lossy-codec frame period."
- **`engineer_profile.compute_spectrum`** uses Butterworth band-pass + RMS while `build_profile.compute_spectrum` uses Welch-PSD band-mean. Both mean-centred, so cohort-MAD absorbs the 0.5–1 dB residual at extreme bands. Aligning to one estimator post-5.2.x removes a category of "why didn't this match" support tickets.
- **AI detector** is honest in code (`probability` aliases `risk_score_raw`); confirm UI/marketing copy says "risk index" not "probability."
- **Radius vocabulary 5-way fractured** (`rounded-full/lg/md/xl/2xl` all in active use). Shell v2 uses `var(--radius-card|pill)` — the right model.
- **`@electron/packager` is a dead dep** alongside `electron-builder`.
- **pip versions have no upper bounds.** Next rebuild could yank a breaking numpy/numba combo.
- **JUCE / ARA path-pinned** with no version. Two engineers building the same tag could ship different binaries.
- **12 versioned `release/v5.x.x/` directories** at ~15 MB each = ~180 MB redundant PDFs in repo. Pruning policy.
- **1 839 lines of uncommitted Shell v2** in working tree. Either land it, branch it, or delete it. Indeterminate is the worst state.
