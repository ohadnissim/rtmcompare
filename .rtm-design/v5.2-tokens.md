# v5.2 Tokens — Console Didone Shell Additions

These tokens extend the existing `@theme` block in `src/styles.css`. They cover only the new surface area introduced in v5.2 (wordmark scale, metric strip, panel verdict, motion, violation alias, overflow menu). Everything else — full color system, base type families, semantic aliases, radius — lives in the existing block and is untouched.

Drop the snippet into `src/styles.css` as a second `@theme` block immediately after the existing one. Tailwind v4 merges multiple `@theme` blocks; this keeps v5.2 additions reviewable in isolation and easy to revert.

---

## Snippet — paste after the current `@theme` block

```css
/* ───────────────────────────────────────────────────────────────────
   v5.2 Console Didone shell — additive tokens.
   Reads from existing tokens; does not redefine any.
   ──────────────────────────────────────────────────────────────────*/
@theme {
  /* ── Wordmark scale ─────────────────────────────────────────────
     Four variants so a single `<Wordmark size="…">` renders in every
     context: header default, dense header (when modes/chips crowd),
     onboarding tour, and empty-state cover. Hero uses clamp() so the
     cover wordmark breathes from a narrow Electron window up to a
     wide external display without ever feeling bolted-down.        */
  --text-wordmark-sm:    1.25rem;                      /* 20px — header dense */
  --text-wordmark-md:    1.875rem;                     /* 30px — header default */
  --text-wordmark-lg:    3rem;                         /* 48px — onboarding */
  --text-wordmark-hero:  clamp(2.5rem, 6vw, 5rem);     /* 40-80px — empty-state cover */

  --leading-wordmark:    1.0;                          /* tight — single line, no wrap */
  --tracking-wordmark:   0.05em;                       /* 5% — refined, not industrial */

  /* ── Metric strip ───────────────────────────────────────────────
     Three sub-tokens: eyebrow (tracked all-caps label), value
     (Didone serif numeral), delta (smaller Didone sibling). The
     eyebrow stays 9px because at 8px it falls under the WCAG
     readability floor on dense displays; 9px tracked-caps in a sand
     hue still reads as a label, not body. Value sized so a four-
     character number ("−7.1") at 28px sits comfortably in a 44px
     row. Delta one step down so it never out-shouts the value.   */
  --text-metric-eyebrow:  0.5625rem;                   /* 9px */
  --text-metric-value:    1.75rem;                     /* 28px */
  --text-metric-delta:    0.875rem;                    /* 14px */

  --leading-metric-value: 1.0;
  --leading-metric-delta: 1.1;
  --tracking-metric-eyebrow: 0.16em;                   /* aggressive tracking — labels announce */
  --tracking-metric-value:   -0.01em;                  /* tighter — numerals are proper names */

  /* ── Panel verdict ──────────────────────────────────────────────
     Hero number scales from 64px (compact panels — Quality, EQ
     Match) to 96px (verdicts that earn the operatic ratio —
     Overview, Mastering Delta). Caption is one short sentence in
     italic display, sand-300, never bolder than 14px so it sits
     beneath the number rather than competing.                     */
  --text-verdict-eyebrow: 0.625rem;                    /* 10px */
  --text-verdict-hero-sm: 4rem;                        /* 64px — compact panels */
  --text-verdict-hero-lg: 6rem;                        /* 96px — primary verdict moments */
  --text-verdict-caption: 0.875rem;                    /* 14px */

  --leading-verdict-hero:    0.95;
  --leading-verdict-caption: 1.4;
  --tracking-verdict-eyebrow: 0.18em;

  /* ── Motion ─────────────────────────────────────────────────────
     v5.2 introduces exactly one new motion (metric strip stagger).
     The other two tokens are for the new tooltip + overflow menu
     to keep them aligned with the strip's rhythm. All motions
     respect `prefers-reduced-motion: reduce` at the component
     level — these tokens are durations only.                      */
  --duration-stagger-cell:   200ms;                    /* per-cell fade-in */
  --duration-stagger-step:   30ms;                     /* delay between cells */
  --duration-tooltip:        120ms;                    /* tooltip in/out */
  --duration-menu:           160ms;                    /* overflow menu in/out */
  --easing-shell:            cubic-bezier(0.32, 0.72, 0, 1);  /* slow-out, used by all v5.2 transitions */

  /* ── Spec-violation alias ───────────────────────────────────────
     `--color-violation` is the SINGLE knob v5.2 components use to
     paint a number that has crossed a delivery-spec threshold.
     Today it maps to the existing `--color-warm-red`. If we ever
     decide violation should be a different hue (e.g. distinguish
     "violation" from "general error"), we change ONE alias and
     every component flips. Components must NEVER reach for
     `--color-warm-red` directly in the v5.2 shell — go through
     this alias.                                                   */
  --color-violation:         var(--color-warm-red);
  --color-violation-soft:    rgba(201,103,101,0.12);   /* delta-cell tint, 12% */

  /* ── Overflow menu ──────────────────────────────────────────────
     Sizing constants only. Colours come from existing semantic
     aliases (`--color-bg-panel`, `--color-text-secondary`, etc.).
     Width chosen so a row "Advanced QC ─────────── ⊙" reads
     comfortably without eating screen real estate.                */
  --w-overflow-menu:        280px;
  --h-overflow-row:         32px;
  --gap-overflow-row:       12px;                      /* between label and control */
  --pad-overflow-menu:      8px;                       /* inner padding around row list */
  --shadow-overflow-menu:   0 8px 24px -8px rgba(0,0,0,0.45),
                            0 1px 0 rgba(255,255,255,0.04) inset;
}
```

## Notes per group

### 1. Wordmark scale
Four sizes prevent the wordmark component from drifting into per-callsite `text-3xl` overrides scattered across the codebase. The hero `clamp()` is the only fluid value — every other shell token is a pinned px because Electron windows don't have meaningful viewport units in the same way a website does. `--leading-wordmark: 1.0` is intentional: the wordmark is one line, never wrapped; tight leading tightens the silhouette.

### 2. Metric strip
The 9 / 28 / 14 px ladder targets a 44px-tall metric cell. At 28px a four-character Didone numeral has the operatic ratio the philosophy calls for; at 32px it would crowd the eyebrow above. Trying 24 px first if the design-review pass thinks 28 is too proud is fine — both stay inside the same cell height.

### 3. Panel verdict
Two hero sizes acknowledge that the seven main panels aren't equal weight. **Overview** and **Mastering Delta** are the primary verdicts — 96 px. **Stereo & Spectrum**, **EQ Match**, **Breakdown**, **Quality**, **Delivery** are 64 px. The 32 px gap between the two scales is what the philosophy calls "the operatic ratio" — visible difference, not subtle.

### 4. Motion
One new motion (stagger), two supporting (tooltip, overflow menu). Easing curve `cubic-bezier(0.32, 0.72, 0, 1)` is the slow-out that lands without bounce — appropriate for tooling that should never feel playful. Reduced-motion handling is per-component, not per-token.

### 5. Spec-violation alias
The discipline here is single-source-of-truth. Every "this metric has violated tolerance" rendering goes through `--color-violation`. If broadcast standards drift and we later want to distinguish a *hard fail* from a *soft warning* visually, we add `--color-violation-soft-fail` as a second alias mapping to `--color-warm-amber`. Components don't change.

### 6. Overflow menu
Sizing-only. Colours inherit. The shadow combines a deep ambient drop plus a 1px inset highlight so the menu reads as a panel sitting *on top of* the dark field, not *cut into* it. This matches the philosophy's "fine printing" vocabulary — a menu is a colophon, not a hole.

---

## What this does NOT add

- **No new font families.** The existing trio (Instrument Serif / Outfit / JetBrains Mono) covers everything.
- **No new color hues.** Every visible color in v5.2 maps to an existing token.
- **No light-mode-specific overrides.** Type sizes and motion durations are theme-agnostic; the violation alias picks up dark/light through its underlying color token. Light-mode audit is out of scope per the brief.
- **No spacing additions.** Tailwind's default scale (already in use) covers v5.2 layouts. If a measurement diverges, it goes through inline `style` with a comment, not a new token, until a pattern emerges.
- **No new radius values.** Sharp + pill remain the only two (audit P2-26 already locked this).
