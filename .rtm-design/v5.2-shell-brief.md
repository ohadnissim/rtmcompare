## Operating discipline (read first)

Read [`.rtm-design/v5.2-anti-ai-design.md`](./v5.2-anti-ai-design.md) before opening any v5.2 file and re-read during every review. ## Problem

The existing shell partially executes Console Didone but the gap between
philosophy and rendered surface is visible to anyone looking. The wordmark
sits in default sans next to dense controls, gold appears 3–4× per screen
diluting its meaning, the metric strip reads as a console toolbar instead
of an instrument panel, and the empty state shows the full chrome of a
loaded session — nothing about the first frame says "you're entering a
quarterly publication." The app is competent. It isn't yet beautiful in
the way a master-level engineer's tools should be.

## Solution

A full shell rebuild that lets Console Didone fully arrive, while preserving
the entire current shell as a one-flag fallback. Two-row top bar gives the
wordmark room and gives metrics typographic dignity. Gold is restricted to
a single anchor (active surface chip) so its appearance again carries
meaning. Empty state becomes a magazine-cover frame. The seven main panel
tabs each get a Didone-promoted verdict number at the top — the one place
each tab "speaks" to the engineer in proper-name register.

## Experience Principles

1. **Restraint earns presence** — Every removal that lands without loss is a win. The shell is judged by what isn't there, not by what is.
2. **Numbers are proper names** — Hero metrics get the Didone treatment; tabular data stays mono. The two contexts never mix in one viewport.
3. **One gold per surface** — Gold means "this is the lens you're reading through." If gold appears twice, one of the two is wrong.

## Aesthetic Direction

- **Philosophy**: Console Didone (defined in `.rtm-design/philosophy.md`). Italian editorial design × mastering console at 3am. Magazine cover first, technical instrument on second glance.
- **Tone**: Quiet, expensive, confident. Authoritative without volume. The 3am studio after the monitors are off.
- **Reference points**:
  - Vogue Italia covers, Monocle quarterly layouts
  - Bottega Veneta wordmark-only campaigns
  - Stanley & Silke book jackets
  - Peter Saville at Factory; Bruno Monguzzi monographs
  - Massimo Vignelli numeric work; Swiss colophon vocabulary
- **Anti-references**:
  - Plugin GUI gloss (Waves, FabFilter chrome)
  - Glassmorphism, neon, gradient stock-AI shine
  - DAW transport-bar density
  - Centred-stack hero pages with three buttons

## Existing Patterns (must respect or extend)

- **Typography**:
  - `--font-display: 'Instrument Serif', 'Cormorant Garamond', Georgia, serif` — already loaded, currently used by `h1`/`h2`. v5.2 extends usage to wordmark and hero metrics.
  - `--font-sans: 'Outfit'` — body, secondary controls, eyebrow tracked-caps. Don't change.
  - `--font-mono: 'JetBrains Mono'` — tabular data only (Loudness Over Time, batch results, EQ tables). Hard rule: never used for hero metrics.
- **Colors** (Tailwind v4 `@theme` tokens, dark and light theme):
  - Cream/ink scale: `--color-sand-50…sand-950` (already WCAG-AAA tuned).
  - Gold: `--color-terra` (`#d0b066`) + `terra-light` + `terra-dark`.
  - Sage (success), warm-red (danger), warm-amber (dynamics), teal (info), slate-blue (File A).
  - Semantic aliases: `--color-text-primary/secondary/muted/dim`, `--color-bg-app/panel/row-hover`, `--color-accent` (= terra), `--color-success/danger/warning`.
- **Spacing**: Tailwind default scale (4 / 8 / 12 / 16 / 24 / 32 px), `max-w-5xl` page width.
- **Radius**: `--radius-card: 2px` and `--radius-pill: 9999px` only — no in-between (audit P2-26).
- **Components reused as-is**: `FileDropZone`, `RecentAnalyses`, `RtmIncomingBanner`, `OnboardingTour`, `ShortcutHelp`, all 22 `*Panel.tsx` components.
- **Architecture**:
  - 28px transparent drag-strip + non-drag `<header>` underneath (Kensington fix). DO NOT MERGE.
  - `ThemeContext` + `data-theme` on `<html>`. Persisted via `localStorage['rtm-theme']`.
  - `ModesContext` for surface / educator / blind / advancedQc.
  - Lazy-loaded views: `AnalysisView`, `RefOnlyView`, `BatchView`.

## Key Interactions

1. **Shell version switch**
   - `localStorage['rtm-shell']` controls v1 / v2. Default `'v2'`.
   - Toggle accessible from OverflowMenu → "Shell version" submenu (radio: v2 New / v1 Classic).
   - Switching applies on next mount of `ShellContext` consumers (no full reload required, since `<header>` re-renders).
   - Surfaces a one-line note in OverflowMenu: "Classic shell preserved as fallback."

2. **Surface chip selection (gold anchor)**
   - One chip is active at any time. Active chip: `bg-terra/18%`, text `terra` (`#d0b066`).
   - Inactive chips: `bg-sand-700/18%`, text `sand-400`.
   - Hover on inactive: text → `sand-200`, no bg change.
   - Keyboard: chip group is a `role="radiogroup"`; arrows move focus, Enter / Space activates.
   - No other element on screen uses `terra` while a surface chip is active. (Zoom != 100% → cream `sand-100`. Blind A/B active → teal. Spec violations → warm-red, never gold.)

3. **Metric strip behaviour**
   - Hidden when `state === 'idle'` or `state === 'loading'` (empty state owns the screen).
   - Visible when `state === 'results'` or `state === 'ref-only'`.
   - On data arrival: each cell fades in from 0.4 → 1 opacity over 200ms, staggered 30ms left-to-right (no transform — the philosophy doesn't slide things).
   - Delta value gold-coloured ONLY when |delta| crosses the per-metric tolerance threshold (defined per metric in `metricSpecs.ts`, new file). Otherwise delta in `sand-300`.
   - Hovering a cell reveals a small tooltip with the spec context (e.g. "Apple Music target: −16 LUFS"). Tooltip uses existing `TooltipPortal` if available; new minimal tooltip if not.

4. **Empty state cover**
   - On first load (no files): hero wordmark centred slightly above optical centre (~40% from top), generous space, drag target at ~60% width, "Drop two audio files to begin" line below in tracked-caps.
   - Single drag-and-drop target accepts both files (existing FileDropZone with `label="A · Reference"` / `B · Mix` flow preserved underneath, but visually unified into one drop frame for v5.2).
   - Colophon bottom strip: `RTMcompare · v{version} · build {date} · {license}` — three centre-dots between segments, all tracked-caps `sand-500` 8pt.
   - Recent analyses: collapsed drawer toggleable from a small "↘ Recent (n)" link in the corner; default collapsed.

5. **Per-panel verdict**
   - Sits at the top of each of the seven main tab panels, before the existing panel content.
   - Three lines: eyebrow ("OVERALL VERDICT" / "MASTERING DELTA" / etc., tracked-caps sand-400 9pt), Didone hero number (size scales by panel — 64–96px), caption (sand-300 italic display 14pt, one short sentence).
   - Verdict source data comes from existing analysis result objects; PanelVerdict is purely presentational, accepts `eyebrow`, `value`, `caption`, optional `violation: boolean` for warm-red treatment.
   - When `state === 'idle'` the panel doesn't render; PanelVerdict only mounts on result.

6. **Overflow menu**
   - `⋯` button (sand-300, hover sand-100) opens a 280px-wide panel anchored to top-right.
   - Panel contains: Advanced QC toggle, Learn mode toggle, Blind A/B toggle (when applicable), zoom controls (− / reset / +), theme switch (dark/light), shell version switch (v2/v1), keyboard shortcuts link.
   - Each item: 32px row, label left, control right. Type uses `font-sans` 13px sand-200.
   - Closes on Esc, click-outside, or focus moving to an element outside the menu.

## Responsive Behavior

This is a desktop-only Electron app. Window minimum is the existing constraint (no mobile). However:

- **Width ≥ 1280px**: Full two-row header with all metric cells visible (4–6 cells depending on surface).
- **Width 960–1279px**: Header rows preserved; metric strip cells reflow to 3-up wrap if needed.
- **Width < 960px (rare, but Electron windows can resize)**: Metric strip collapses to a horizontal scroll row with a fade gradient at the right edge to indicate overflow. Surface chips remain visible.
- The 28px drag strip + sticky header behaviour is preserved at all widths.
- Empty state hero wordmark uses `clamp(2.5rem, 6vw, 5rem)` so it scales down gracefully if the window is narrowed.

## Accessibility Requirements

- **Contrast (hard floor)**:
  - All text WCAG-AA at 12px, AAA at 14px+ (continues current standard).
  - Hero Didone numbers (large, ≥32px): AA only is acceptable per WCAG large-text rule, but we target AAA.
  - Gold `terra` (`#d0b066`) used on `sand-950` background = 8.4:1 → AAA.
  - Gold on `sand-700/18%` chip background = effectively the same on dark base → AAA.
- **Keyboard navigation**:
  - All chips, buttons, overflow menu items reachable in tab order.
  - Surface chip group: arrow-key navigation as above (radiogroup pattern).
  - Overflow menu: focus trap when open, Esc closes and returns focus to `⋯` button.
  - Drag target in empty state: focusable, Space / Enter triggers file picker (existing `handleClick` in FileDropZone).
- **Screen reader**:
  - Wordmark: `aria-label="RTMcompare"`, `role="img"` (since we're treating it typographically, not as plain text the SR should announce as "RTM compare" letter-by-letter).
  - Surface chips: `role="radiogroup"` with `aria-label="Delivery target"`, each chip `role="radio"` `aria-checked`.
  - Metric cells: `aria-label` combines eyebrow + value + delta into one announcement (e.g. "LUFS-I, integrated loudness, minus seven point one, two point eight louder than reference").
  - Empty state colophon: `aria-hidden="true"` (decorative).
- **Focus rings**:
  - Custom focus ring: 2px outline using `--color-accent` (terra) at 50% opacity, offset 2px. Shows only on `:focus-visible`.
  - On chips, focus ring is inside the pill (no layout shift).
- **Reduced motion**:
  - Metric strip stagger fade-in respects `prefers-reduced-motion: reduce` → instant render.
  - Tooltip / overflow menu transitions respect the same.

## Out of Scope (v5.2 — defer to later)

- **Verdict-headline-on-every-panel work** beyond the seven main tabs. Atmos panels, AI Detection, Phase Bands, Masking, Tempo Drift, Distortion, Hum, Declick, Limiter Artefacts, Translation Check, Metadata, Master Assistant, Atmos QC, Atmos Object Anomaly, Atmos Object View, Song Detail, Engineering Tips — all keep current treatment until v5.3.
- **Marketing/landing site redesign**. Separate track, separate cadence.
- **Dark/light theme audit**. Theme system stays as is. New components must work in both, but no audit pass on existing components.
- **Mobile / iPad adaptation**. Desktop Electron only.
- **New animation language**. v5.2 introduces only one motion: the staggered fade-in on metric strip. No additional easing, parallax, scroll-driven motion, or video.
- **Empty state for Batch and Ref-Only modes**. Both keep current treatment in v5.2; cover-page only applies to the Compare-mode primary empty state.
- **Brand mark / logo creation**. No new monogram or logomark in v5.2; wordmark only.
- **Audio waveform / spectrogram visual restyle**. Existing components (`WaveformCompare`, `SpectrumOverlay`, etc.) keep current chroma. Restyling them is its own brief.
- **Shortcut overlay redesign** (`ShortcutHelp.tsx`). It already works; re-skin in v5.3 if needed.
- **PDF / HTML report restyle** (`ExportButton.tsx`). Reports are downstream artifacts; their style should follow but lags one version.

## Acceptance criteria (the v5.2 ship checklist)

A v5.2 build is "shippable" when, in the new shell:

1. The wordmark renders in Instrument Serif at `text-3xl`, in both empty and loaded states.
2. Gold appears in exactly one place per screen: the active surface chip. Programmatic check: `document.querySelectorAll('[data-gold]').length === 1` after first mount.
3. The metric strip is two-line per cell (eyebrow + value), uses Didone for values, and shows delta gold only when violating a per-metric tolerance.
4. Empty state shows: hero wordmark, "Drop two audio files…" line, single drag target, colophon at bottom.
5. Each of the seven main tab panels has a `<PanelVerdict>` at the top.
6. `localStorage['rtm-shell'] = 'v1'` reverts the entire shell to current behaviour with no visual regressions vs. v5.1.2.
7. WCAG-AA at 12px, AAA at 14px+ holds across the new shell, dark and light themes both.
8. The Kensington drag-region architecture (line 851–865) is byte-for-byte preserved.
9. `prefers-reduced-motion: reduce` produces no animations.
10. The seven existing tab panels load and behave identically to v5.1.2 except for the `<PanelVerdict>` insert at top.
