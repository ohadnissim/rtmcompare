## Known intentional divergence from v5.1.x

1. **OnboardingTour wordmark** — now Instrument Serif at 48px (`<Wordmark size="lg" />`) instead of Outfit at 30px. The brief promotes this app-wide. If you'd prefer to keep v1 onboarding pre-v5.2, gate the swap on `shellVersion === 'v2'`.
2. **Splash bug fix in `electron/main.ts:105`** — was loading from `<projectRoot>/../build/splash.html` (wrong directory), now loads from `<projectRoot>/build/splash.html`. Both shells benefit.
3. **`useMemo` import added to `ModesContext.tsx`** — fixes the pre-existing runtime crash noted in code comments.

These three are the only behaviour changes that affect v1. Everything else in v5.2 is opt-in via `localStorage['rtm-shell'] = 'v2'` (now the default).
