## 9 · `[COMPOSITE]` `<MetricStrip>` — staggered fade-in row

**Files:** `src/components/shell/MetricStrip.tsx` (new), possibly `src/lib/metricSpecs.ts` (new) for tolerance thresholds
**What:**
- Props: `cells: { eyebrow: string; value: string; delta?: string; violation?: boolean; tooltip?: string }[]`.
- Renders a horizontal row of `<MetricCell>` instances, each with `animation-delay: calc(var(--duration-stagger-step) * index)` and a 200ms fade-from-0.4 opacity.
- Respects `prefers-reduced-motion: reduce` → no animation, instant render.
- Reflows at narrow widths: `flex-wrap` allowed; below 960px, switch to a horizontally scrollable row with a fade gradient at the right edge.
- `metricSpecs.ts` defines per-metric tolerance thresholds (e.g. LUFS-I delta tolerance ±1 LU, TP delta ±0.3 dBTP). Helper `isViolation(metricKey, deltaValue)` → boolean. The strip uses this to set the `violation` prop on each cell.
**Acceptance:**
- Mounted with 6 cells, all fade in over ~380ms total (200 + 5×30).
- `prefers-reduced-motion: reduce` skips animation entirely.
- A delta of `+2.8` for LUFS-I (tolerance ±1) renders gold; `+0.4` does not.
**Depends on:** #1, #5
