# v5.2 Gold Budget

One rule, four audiences, one promise per surface.

## The rule

**One gold per view. Gold marks the irreversible commitment.**

Gold is the colour of the hand pausing. The export. The release. The submit. The approve. Everything else can be sand, cream, sage, amber, or warm-red — but the gold is reserved for the one move on the surface that the user cannot quietly walk back.

Engineers' eyes calibrate to the cream-on-ink field within seconds. Spend gold on a tab strip, on a stat number, on a hover state, and the calibration breaks — the eye starts treating gold as decoration. Reserve it for commitment and the hand pauses in the right place every time.

## Per-audience map

| Audience | Where the gold lives (max 1 per view) |
|---|---|
| **PRO** | CoverSurface hairline + 2px left-rule per slot · Verdict diamond (decorative, upper-right) · Delta annotation 2px left-rule + italic 48px Δ value · primary CTA: "Export final master" / "Generate certificate" |
| **PRODUCER** | CoverSurface hairline · Verdict diamond · Release-Readiness Δ value per platform row · "Master for release" CTA (gold only when all four platforms pass) |
| **STUDENT** | DrillCard "Start drill →" CTA · rubric target tick on the meter when the answer reveals · "Submit assignment" |
| **TEACHER** | TeacherDashboard "EXPORT GRADEBOOK" CTA · rubric target ticks in the spec column · "Approve" (when the verdict is APPROVED) |

## Where gold does NOT live

- Eyebrows and section headers (sand-400)
- Tab strips and active tabs (cream underline, 1px)
- Hover states (sand-800 fill, never gold)
- Progress bars and meters (severity colours: sage / warm-amber / warm-red)
- Stat numbers and metric values (cream, JetBrains Mono)
- Navigation, breadcrumbs, file paths

## The corollary

A view that earns zero gold is a valid view. Absence is the discipline. The Cover before files load, the empty drill list, the teacher dashboard with no submissions — none of these carry gold. The first commitment-move is what earns it.
