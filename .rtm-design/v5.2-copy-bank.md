# v5.2 Copy Bank

`src/copy/v52.ts` is the canonical store for every string in RTMcompare v5.2 that varies by audience. Four audiences are supported today: **pro**, **producer**, **student**, **teacher**.

## Why a copy bank exists

Audience-aware surfaces (Cover, Verdict, CTA, Certificate) ship four wordings per string. Inlining those switches in components scatters tone decisions across the tree and makes brand-voice review impossible — every refactor risks drifting the language. The bank centralises copy so:

- A single PR can change tone across all surfaces.
- A linter / grep pass can verify no component hardcodes audience-varying strings.
- Tests can render every audience × surface combination from one fixture.

**Hard rule:** components MUST NOT hardcode audience-varying strings. Reach into `v52Copy.<surface>.<field>[audience]`, or use the `pickV52(surface, field, audience)` helper for autocomplete.

## How to add a new surface

1. Add an interface in `src/copy/v52.ts` describing every field on the surface, each typed as `ByAudience<T>` (string, or a templating function such as `(c: GreetingCtx) => string`).
2. Add the interface to `V52Copy`.
3. Populate `v52Copy.<surface>` with all four audiences for every field. **No partials** — if you don't have copy for one audience, write a placeholder string and flag it `TODO`. Missing keys break the `ByAudience<T>` type contract.
4. Document the surface in this file under a new heading.

Naming convention: surfaces are lowercase singular nouns (`cover`, `verdict`, `cta`, `certificate`). Fields are camelCase (`valueProp`, `eyebrow`, `primary`).

## How to add a new audience

The bank uses `Audience = 'pro' | 'producer' | 'student' | 'teacher'`. To add a fifth (e.g. `'label'`):

1. Extend the `Audience` union in both `src/copy/v52.ts` and `src/AudienceContext.tsx`.
2. Update the signal-mapping cascade in `useAudience()` so the new audience can actually be resolved.
3. TypeScript will now flag every `ByAudience<T>` literal as incomplete — add the new audience to every entry. This is the point: the type system forces full coverage.
4. Update tests / Storybook fixtures that iterate audiences.

## Signal source

Audience is resolved by `useAudience()` in `src/AudienceContext.tsx`. Priority: `localStorage.rtm-audience` override → LearnMode role → `localStorage.rtm-persona === 'producer'` → default `pro`.
